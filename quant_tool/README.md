# 量化交易回测工具 · 入门原理与使用指南

> 给非金融、非计算机背景的你：量化交易到底在干嘛？

---

## 一、量化交易的本质

**把"我觉得这只股票要涨"变成"当 X 条件满足时，自动买入"，然后用历史数据验证这个规则能不能赚钱。**

主观交易 vs 量化交易：

| | 主观交易 | 量化交易 |
|---|---|---|
| 决策依据 | 看新闻、盘感、朋友推荐 | 写好的规则/数学模型 |
| 情绪影响 | 追涨杀跌、贪婪恐惧 | 机器执行，不带情绪 |
| 可重复性 | 每次操作理由都不一样 | 同一条件永远同一操作 |
| 最大问题 | 事后诸葛亮，不知道自己对在哪 | 过拟合——历史能赚，未来不赚 |

## 二、一个完整量化系统长什么样？

```
数据获取 → 策略信号 → 回测验证 → 实盘执行
   ↑           ↑          ↑          ↑
  本工具✅   本工具✅    本工具✅    你以后自己接券商接口
```

### 1. 数据获取
做量化的第一步是有"历史K线数据"。K线就是每天的：开盘价、最高价、最低价、收盘价、成交量（OHLCV）。
本工具用 [AkShare](https://akshare.akfamily.xyz/) 免费拉A股数据，自动缓存到本地 SQLite。

### 2. 策略信号
策略就是一个"规则函数"：输入历史价格，输出每天应该买还是卖。
本工具内置两个经典策略：

- **双均线交叉**（趋势跟踪）：短期均线上穿长期均线 = 金叉 = 买入；下穿 = 死叉 = 卖出。
  - 逻辑：最近5天的平均价格比最近20天的高，说明短期买盘强，趋势向上。
- **RSI 均值回归**（逆向操作）：RSI < 30 超卖买入，RSI > 70 超买卖出。
  - 逻辑：跌太狠了会反弹，涨太猛了会回调。

> ⚠️ 这两个策略思路完全相反：一个追涨杀跌，一个低买高卖。没有谁对谁错，赚不赚钱要看市场环境。

### 3. 回测验证
回测 = 把历史数据喂给策略，模拟"如果当时按这个规则操作"，最后算赚了多少。

**关键指标怎么看：**

| 指标 | 含义 | 多少算好 |
|---|---|---|
| 总收益率 | 整个期间赚了百分之几 | 跑赢"一直持有"就及格 |
| 最大回撤 | 从最高点跌到最低点最惨亏多少 | 越小越好，<20%算稳 |
| 夏普比率 | 每冒1块钱风险能赚多少 | >1不错，>2优秀 |
| 交易次数 | 一共买卖了几次 | 太少=策略太钝，太多=手续费吃掉利润 |

### 4. 实盘执行（本工具不做）
回测赚钱后，接券商API（如华泰PTrade、QMT）自动下单。这步要真金白银，建议先模拟盘跑半年。

## 三、新手最容易踩的坑（重要！）

1. **未来函数**：用当天收盘数据算信号，当天收盘就买卖——实际你做不到。本工具用 `shift(1)` 把信号延后一天执行，这是对的。
2. **过拟合**：在历史数据上把参数调到完美（比如MA5改成MA7），一到实盘就亏。因为你在"拟合历史噪音"。
3. **忽略手续费和滑点**：每次买卖都要交佣金+印花税，高频策略光手续费就能亏死。
4. **只看收益不看回撤**：一年赚50%但中间先亏了40%，你拿得住吗？大部分人拿不住。
5. **单只股票单段历史**：一个策略在茅台上赚钱不代表在宁德时代上也赚钱。要多股票、多时间段测试。

## 四、怎么运行

### 方式一：本地直接跑（推荐先试这个）

```bash
# 1. 进入项目目录
cd quant_tool

# 2. 安装依赖（建议先建虚拟环境）
pip install -r requirements.txt

# 3. 启动服务
uvicorn app.main:app --reload --port 8000
```

浏览器打开 http://localhost:8000 就能用。

### 方式二：Docker 一键启动

```bash
cd quant_tool
docker-compose up -d
```

## 五、继续深入路径

1. **先把本工具跑通**，换不同股票、不同时间段、不同策略对比
2. **加一个新策略**：在 `app/strategies.py` 里照着写一个函数，注册到 `STRATEGIES` 字典
3. **学一个进阶策略**：比如动量因子（过去N天涨得好的继续涨）、布林带
4. **学多因子选股**：不只做一只股票，而是每天从全市场选最强的5只
5. **学风险控制**：仓位管理、止损止盈、对冲

> 建议入门路线：先用本工具理解"信号→回测→指标"这套流程，再去看《打开量化投资的黑箱》《量化投资策略与技术》这类书，就不会觉得天书了。

## 六、文件结构说明

```
quant_tool/
├── app/
│   ├── main.py           # FastAPI 接口入口
│   ├── data_fetcher.py  # 数据获取（AkShare + 本地缓存）
│   ├── strategies.py     # 策略定义（双均线、RSI）
│   ├── backtester.py    # 回测引擎（算收益、回撤、夏普）
│   ├── database.py       # SQLite 表结构
│   └── static/
│       └── index.html    # 前端可视化页面
├── requirements.txt      # Python 依赖
├── Dockerfile            # 容器化
├── docker-compose.yml    # 一键启动
└── README.md             # 本文件
```
